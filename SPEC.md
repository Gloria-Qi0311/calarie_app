# NourishFlow UI Spec

Create a polished mobile-first UI in Next.js + Tailwind CSS for two pages:

1. **Onboarding** (`/`)
2. **Home Dashboard** (`/dashboard`)

## Design Requirements

- Match provided Figma screenshots as closely as possible.
- Soft neutral background.
- Rounded cards with subtle shadows and borders.
- Bold navy headline text.
- Muted body copy.
- Warm gradient CTA button.
- Maintain spacing rhythm and visual hierarchy.

## Technical Requirements

- Use reusable UI components.
- Keep code clean and split by concerns.
- Responsive layout for small and large screens.
- No backend logic.
- Include clean typography and consistent icon treatment.
